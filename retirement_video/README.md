# 퇴임식 기념영상 제작기

사진·동영상을 날짜순으로 정리하고 음악 분석 결과에 맞춰 타임라인 초안을 만든 뒤 Full HD MP4로 출력하는 Windows용 프로그램입니다. 원본 파일은 읽기만 하며 프로젝트에는 편집 설정만 저장합니다.

## 실행

Windows 11에서 Python 3.11 이상을 설치한 뒤 `run_windows.bat`을 더블클릭합니다. Python 설치 시 `Add Python to PATH`를 선택해야 합니다. 처음 실행할 때 `install_windows.bat`이 전용 가상환경과 필요한 무료 라이브러리를 설치하므로 인터넷 연결이 필요합니다.

MP4 출력과 동영상 분석에는 FFmpeg가 필요합니다. 터미널에서 `winget install --id Gyan.FFmpeg -e`를 실행한 뒤 Windows를 다시 로그인하거나 재부팅하면 됩니다. FFmpeg가 없어도 프로그램을 열어 사진을 불러오고 프로젝트를 편집할 수 있습니다.

실행에 실패하면 검은 창이 사라지지 않고 `STARTUP ERROR`와 원인을 표시합니다. 그 내용을 복사하거나 사진으로 찍어 문제를 진단할 수 있습니다. Windows 명령 프롬프트의 한글 인코딩 문제를 피하기 위해 실행 스크립트의 진단 문구는 영어로 표시됩니다.

개발 환경에서는 다음 명령을 사용합니다.

```powershell
py -3.11 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-dev.txt
.venv\Scripts\python main.py
```

## 날짜와 챕터 인식 규칙

프로그램은 EXIF 또는 동영상 촬영 메타데이터를 우선 사용합니다. 메타데이터가 없으면 선택한 폴더 내부에서 가까운 폴더명부터 검사하고, 마지막으로 파일명을 검사합니다.

인식 예시는 다음과 같습니다.

- `2005년_함께 걸어온 시간/IMG_001.jpg` → 2005년, 챕터 `함께 걸어온 시간`
- `2장 동료들과의 추억/2015.04.03_행사.jpg` → 2015-04-03, 챕터 `동료들과의 추억`
- `챕터 4 새로운 출발/20260708.jpg` → 2026-07-08, 챕터 `새로운 출발`
- `1998/송별회_01.jpg` → 1998년, 챕터 `1998년`

지원 날짜 표기는 `YYYYMMDD`, `YYYY-MM-DD`, `YYYY.MM.DD`, `YYYY년 M월 D일`, `YYYYMM`, `YYYY-MM`, `YYYY년`, `YYYY`입니다. 날짜의 연·월·일 정밀도는 프로젝트에 보존됩니다. 자동 결과는 왼쪽 목록에서 확인하고 `날짜 수정` 및 오른쪽 `챕터` 항목으로 고칠 수 있습니다.

## 현재 구현 기능

- 파일/폴더 및 끌어놓기 불러오기, 하위 폴더 검색, 중복 감지
- 원본을 화면에 직접 올리지 않는 디스크 썸네일 캐시로 300개 미디어 목록 관리
- EXIF·동영상 메타데이터·폴더명·파일명 날짜 분석
- 폴더명/파일명 챕터 분석, 날짜순 정렬, 수동 날짜 수정
- 타임라인 끌어놓기 정렬, 재생시간·전환·중요도·자막 편집
- 사진별 왼쪽 90도·오른쪽 90도·180도 비파괴 회전
- MP3/WAV/M4A/FLAC 음악 BPM·비트·에너지 분석 및 캐시
- 스타일, 목표 길이, 최소/최대 시간, 동기화 강도 기반 자동 편집
- JSON 프로젝트 저장/열기, 1분 자동 저장, 실행 취소/다시 실행
- 다른 PC 이동용 프로젝트 패키징
- 사진 모자이크 데이터를 렌더링하는 비파괴 출력 엔진
- 인트로·챕터·엔딩을 포함한 H.264/AAC MP4 출력
- 빠른 출력(1280×720)과 Full HD 출력(1920×1080), 장면별 출력 진행률 표시

현재 미리보기는 사진 정지 화면 중심이며 동영상·전환·음악의 정확한 결과는 MP4 출력으로 확인합니다. 출력 엔진은 안정적인 페이드 장면 연결을 우선 구현했으며, GUI에서 고른 슬라이드/Ken Burns 전환의 고유 동작과 대화형 모자이크 영역 편집은 후속 확장 지점입니다.

## 테스트와 EXE

```powershell
.venv\Scripts\python -m pytest
build_exe.bat
```

`build_exe.bat`은 PyInstaller 실행 폴더를 `dist` 아래에 만듭니다. FFmpeg는 라이선스와 업데이트 관리를 위해 자동으로 묶지 않으므로 설치본과 함께 별도 배포하거나 사용 PC의 `PATH`에 등록해야 합니다.

문제가 생기면 `%USERPROFILE%\.retirement_video\application.log`를 확인합니다. 자동 저장 파일은 같은 폴더의 `autosave.retirevideo`, 음악 분석 캐시는 `audio_cache`에 있습니다.
